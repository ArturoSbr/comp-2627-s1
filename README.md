# Computational and Statistical Tools

Welcome! This course is designed to teach you the theory and skills needed to do
robust empirical research in Economics. Since this is an *applied* course, we
will mainly focus on tools, such as bash, git and Python during our first
semester.

## Syllabus

1. Tech-Stack
    * Bash
    * Git & GitHub
    * Python
2. Linear Regression
3. Generalized Linear Models
4. Neural Networks
